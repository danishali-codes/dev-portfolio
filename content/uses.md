# Uses

What the projects on this desktop are built with.

## This site

React, TypeScript and Vite, with Zustand for the windows. Deployed on Vercel.

## Apps

Fuloos and Lockout are React and TypeScript on Vite. Lockout also uses Tailwind,
Radix UI and Framer Motion. Both keep their data in PocketBase, and Fuloos is
deployed on Vercel.

## Models

Python and PyTorch for the coursework, and scikit-learn for Ledger. Ledger
answers questions with Qwen2.5 in the browser through WebLLM.

## Games

Unity and C#, played in the browser on itch.io.

## Hardware

- **GPU:** NVIDIA RTX 4070 Ti, for local training.
